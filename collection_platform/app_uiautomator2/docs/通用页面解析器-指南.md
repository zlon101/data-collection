# 通用页面解析器 - 使用指南

## 📖 概述

通用页面解析器（UniversalPageParser）是一个智能的移动端页面数据抓取工具，具备以下特性：

- ✅ **自动分屏解析**：无需手动指定字段所属屏幕，自动滚动查找
- ✅ **智能底部检测**：通过 resourceId 精确识别页面底部
- ✅ **多元素处理**：支持正则过滤，避免 resourceId 重复问题
- ✅ **可选字段支持**：区分必填和可选字段
- ✅ **详细错误信息**：报错时提供表格和解决建议
- ✅ **安全阈值保护**：防止底部标识配置错误导致无限滚动

---

## 🚀 快速开始

### 1. 基础使用

```python
import uiautomator2 as u2
from lib import DetailPageSpiderUniversal, ListPageSpider

device = u2.connect()

# 配置详情页爬虫
detail_spider = DetailPageSpiderUniversal(
    device=device,
    detail_selectors={
        "字段名": {
            "resourceId": "com.xxx:id/xxx",
            "optional": False
        }
    },
    bottom_indicator_resourceId="com.xxx:id/bottom_indicator",
    verbose=True
)

# 在列表页爬虫中使用
def on_item_found(container_element, list_item_data):
    return detail_spider.process_single_item(container_element, list_item_data)

list_spider = ListPageSpider(
    device=device,
    container_selector="com.xxx:id/container",
    selectors={...},
    item_processing_callback=on_item_found
)

list_spider.crawl()
```

## 📝 配置格式

### 字段选择器配置

```python
selectors = {
    "字段名": {
        "resourceId": "字符串",        # 必填：元素的 resource-id
        "textPattern": "正则表达式",   # 可选：文本过滤（包含匹配）
        "optional": True/False,       # 可选：是否可选字段，默认 False
    }
}
```

### 示例

```python
selectors = {
    # 最简配置：只有 resourceId
    "详细地址": {
        "resourceId": "com.hpbr.bosszhipin:id/tv_required_location"
    },
    
    # 必填字段
    "职位描述": {
        "resourceId": "com.hpbr.bosszhipin:id/tv_description",
        "optional": False
    },
    
    # 可选字段
    "活跃度": {
        "resourceId": "com.hpbr.bosszhipin:id/boss_label_tv",
        "optional": True
    },
    
    # 使用正则过滤（解决 resourceId 重复问题）
    "距离": {
        "resourceId": "com.hpbr.bosszhipin:id/tv_title",
        "textPattern": r"\d+\.?\d*\s*(km|m)",  # 匹配 "1.2km" "500m"
        "optional": True
    }
}
```

## 🔧 参数说明

### DetailPageSpiderUniversal 参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `device` | u2.Device | 必填 | uiautomator2 设备对象 |
| `detail_selectors` | Dict | 必填 | 详情页字段选择器配置 |
| `bottom_indicator_resourceId` | str | 必填 | 底部标识元素的 resourceId |
| `max_scroll_times` | int | 10 | 最大滚动次数（安全阈值） |
| `scroll_from` | float | 0.7 | 滚动起点Y坐标比例 |
| `scroll_to` | float | 0.3 | 滚动终点Y坐标比例 |
| `scroll_duration` | float | 0.3 | 滚动持续时间（秒） |
| `scroll_wait` | float | 0.5 | 滚动后等待时间（秒） |
| `click_wait` | float | 2.0 | 点击后等待时间（秒） |
| `back_wait` | float | 1.5 | 返回后等待时间（秒） |
| `verbose` | bool | False | 是否输出详细日志 |

## 📋 使用步骤

### 步骤1：确定底部标识

使用 UI Automator Viewer 查看页面底部的唯一标识元素：

```bash
# 连接设备
adb shell uiautomator dump /sdcard/window_dump.xml
adb pull /sdcard/window_dump.xml

# 打开 XML 文件
# 找到页面底部的唯一元素，如 "请立即举报" 按钮
# 记录其 resource-id，如: com.hpbr.bosszhipin:id/report_button
```

**要求**：
- ✅ 必须在页面底部
- ✅ 每个页面都有
- ✅ resourceId 唯一（不与其他元素重复）

---

### 步骤2：配置字段选择器

```python
detail_selectors = {
    # 第1屏字段（进入页面立即可见）
    "字段A": {
        "resourceId": "com.xxx:id/xxx",
        "optional": False  # 必填
    },
    
    # 第2屏字段（需要滚动）
    "字段B": {
        "resourceId": "com.xxx:id/xxx",
        "textPattern": r"正则表达式",  # 如果 resourceId 重复，添加此项
        "optional": True  # 可选
    }
}
```

**注意**：
- 无需指定字段在哪一屏，解析器会自动滚动查找
- 如果 resourceId 可能重复，务必添加 `textPattern`

## ⚠️ 常见问题

### 问题1：MultipleElementsError - 匹配到多个元素

**错误信息**：
```
❌ 字段 '距离' 匹配到多个元素 (共 3 个)

┌──────────────────────────────────────┐
│           匹配的元素详情              │
├───────┬────────────┬──────────────────┤
│ 索引  │  文本内容   │   坐标 (bounds)   │
├───────┼────────────┼──────────────────┤
│  0    │ 1.2km      │ [70,1293][322...]│
│  1    │ 员工福利    │ [70,500][322...] │
│  2    │ (空)       │ [70,2100][322...]│
└───────┴────────────┴──────────────────┘

💡 解决方案:
  添加 textPattern 过滤
```

**解决方法**：

```python
# 添加正则过滤
"距离": {
    "resourceId": "com.hpbr.bosszhipin:id/tv_title",
    "textPattern": r"\d+\.?\d*\s*(km|m)"  # 只匹配距离格式的文本
}
```

---

### 问题2：ParseTimeoutError - 达到最大滚动次数

**错误信息**：
```
❌ 解析超时

滚动次数: 10 (已达上限)
底部标识配置: resourceId=com.xxx:id/bottom
检测结果: 未检测到底部标识元素
```

**可能原因**：
1. bottom_indicator_resourceId 配置错误
2. 页面非常长，10次不够
3. 底部标识未加载出来

**解决方法**：

```python
# 方法1：增加滚动次数
max_scroll_times=20

# 方法2：检查底部标识配置
# 使用 UI Automator Viewer 验证 resourceId 是否正确

# 方法3：使用 verbose=True 查看详细过程
verbose=True
```

---

### 问题3：BottomReachedError - 到达底部但字段未找全

**错误信息**：
```
❌ 已到达页面底部，但必填字段未找全

未找到的必填字段 (1个):
  ❌ 职位描述:
      resourceId: com.xxx:id/tv_description
      optional: False
```

**可能原因**：
1. 字段 resourceId 配置错误
2. 页面确实没有该字段
3. textPattern 过滤条件过于严格

**解决方法**：

```python
# 方法1：检查 resourceId 是否正确
# 使用 UI Automator Viewer 验证

# 方法2：如果字段不是必需的，改为可选
"职位描述": {
    "resourceId": "...",
    "optional": True  # 改为可选
}

# 方法3：放宽 textPattern 条件
"距离": {
    "resourceId": "...",
    "textPattern": r".*km.*"  # 更宽松的匹配
}
```

## 🎯 最佳实践

### 1. 字段配置原则

```python
# ✅ 好的配置
selectors = {
    # 必填字段：核心业务数据
    "职位名称": {
        "resourceId": "...",
        "optional": False
    },
    
    # 可选字段：补充信息
    "距离": {
        "resourceId": "...",
        "textPattern": r"\d+\.?\d*\s*(km|m)",
        "optional": True  # 有些职位可能没有距离
    }
}

# ❌ 不好的配置
selectors = {
    # 所有字段都设为必填
    "距离": {
        "resourceId": "...",
        "optional": False  # ❌ 如果某些页面没有，会报错
    }
}
```

---

### 2. textPattern 正则建议

```python
# ✅ 精确匹配
"距离": {
    "resourceId": "...",
    "textPattern": r"\d+\.?\d*\s*(km|m)"  # 匹配 "1.2km" "500m"
}

# ✅ 包含关键词
"公司福利": {
    "resourceId": "...",
    "textPattern": r"(五险|六险|餐补|房补)"  # 匹配包含这些词的文本
}

# ❌ 过于宽松（容易误匹配）
"距离": {
    "resourceId": "...",
    "textPattern": r"m"  # ❌ 会匹配 "team", "employee" 等
}
```

---

### 3. 调试流程

```python
# 步骤1：开启详细日志

# 步骤4：根据日志调整配置

# 步骤5：增加数据量测试
```

## 📊 性能优化

### 1. 合理设置滚动参数

```python
# 默认配置（适合大多数情况）
scroll_from=0.7,
scroll_to=0.3,
scroll_duration=0.3,
scroll_wait=0.5

# 快速模式（页面加载快）
scroll_duration=0.2,
scroll_wait=0.3

# 稳定模式（页面加载慢）
scroll_duration=0.5,
scroll_wait=0.8
```

---

### 2. 减少不必要的滚动

```python
# ✅ 按重要性排序字段（重要字段先配置）
selectors = {
    "职位名称": {...},    # 通常在第1屏
    "薪资": {...},        # 通常在第1屏
    "详细地址": {...},    # 通常在第1屏
    "距离": {...}         # 通常在第2屏
}

# 解析器会优先尝试第1屏的字段
# 如果第1屏全部找到，可能不需要滚动
```
