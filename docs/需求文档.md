# 需求文档

以当前产品行为为准。早期「左右侧栏 + 独立日志页 + 情感仪表盘」未按原文落地。

## 运行方式

1. 调试 Chrome：`./scripts/run_chrome.sh`，打开要采的页面  
2. 后端：`uv run uvicorn backend.main:app --reload --port 8000`  
3. 前端：`cd frontend && npm run dev`（`http://localhost:5173`）  
4. 可选：自然语言采集见 [技术方案.md](./技术方案.md) 中 scrape_agent  

## 前端

技术栈：Vite + Vue3 + ant-design-vue + axios + ECharts。

**布局**：顶部 Tab「爬虫」「查询」（不是左侧菜单）。

| 模块 | 需求 | 现状 |
|------|------|------|
| 爬虫 | 浏览器 / App 参数配置并启动采集 | 已实现：Browser / Boss / 智联表单、配置存取、任务启停、日志弹窗 |
| 查询 | `local_data/job` 表格；活跃度、最低薪资、最大距离筛选 | 已实现；另有来源、日期、已读、Job 文件管理 |
| 日志 | 查看 backend 运行日志 | **无独立页**；采集日志在爬虫页弹窗 |

浏览器表单支持列表选择器、字段、分页、可选详情（手动填 CSS）。App 走 uiautomator2 启动器。

## 浏览器智能配置（CLI）

不替代手动表单。用户用自然语言描述目标，Agent 生成配置、试抓确认后再全量。

能力：单页模块列表、多页（下一页按钮）、列表+详情（无真实 URL 时点击列表项）。试抓与全量的错配风险见技术方案。

## 其它能力（非前端主路径）

- 微信公众号采集与招聘文章视觉/OCR 分析（`wx`）  
- App：Boss / 智联 / Airtest 微信  
- Job 已读、文件合并去重  
- `ai_agent` 文章摘要/情感/实体（Query 主界面以招聘表为主，分析 API 仍保留）
