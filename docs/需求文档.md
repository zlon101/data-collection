# 项目运行流程
1. 执行命令启动前端frontend 和 后端backend
2. 前端页面触发各种操作（参考“前端需求”），调用 backend api



# 前端需求


## 功能
1. 爬虫: 数据抓取，支持浏览器页面、app抓取，并且支持在页面上配置抓取参数
2. 查询: 读取 LOCAL_DATA_DIR / job 目录下的 json 文件，以 table 的形式展示，并且支持按照“活跃度”、“最低薪资”、“最大距离”筛选
3. 日志: 查看 backend 运行日志


## UI

### 布局
左右布局，左侧菜单栏，右侧内容区域，菜单栏包含：爬虫、查询、日志


## 技术栈

vite + vue3 + ant-design-vue + axios
