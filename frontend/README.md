# 职位数据查看器

## 安装依赖
```bash
npm install
```

## 数据合并与去重
执行以下命令批量读取 `job` 目录中的所有JSON文件，合并并按 `unique_key` 去重：
```bash
npm run merge
```
合并后的数据将保存到 `merged_data.json` 文件。

## 启动开发服务器
```bash
npm run dev
```

## 功能说明
- **数据合并工具**：批量读取 `job` 目录中所有JSON文件，按 `unique_key` 去重并保存
- **表格展示**：显示合并后的所有职位数据
- **薪资筛选**：输入最低薪资（万元），筛选大于等于该值的职位
- **活跃度筛选**：支持模糊匹配，使用 `|` 分隔多个关键词（或关系）
- **距离筛选**：输入最大距离（千米），筛选小于等于该值的职位
- **公司搜索**：输入公司名称进行模糊搜索
- **排序**：支持按薪资和距离排序
